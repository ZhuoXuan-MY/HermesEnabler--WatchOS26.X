# HermesEnabler · watchOS 26.x Kompatibilitätsforschung

**Status: BLOCKED — Der bisherige Ansatz ist blockiert. Native Hermès-Zifferblätter wurden nicht freigeschaltet.**

Dieses Repository dokumentiert meine Untersuchungen mit einer **Apple Watch Ultra der ersten Generation (Watch6,18 / n199ap)** unter **watchOS 26.6.1 (23U95)**.

Der geschützte MobileGestalt-Cache ließ sich lesen, aber der Schreibzugriff wurde mit `EPERM` verweigert. Zusätzlich bestehen unabhängige Zulassungsprüfungen in ClockKit/NanoTimeKit. **Das Repository ist kein funktionsfähiges Entsperrwerkzeug und bietet keine nachweislich funktionierende IPA.**

`RO23` in älteren Dateinamen ist eine interne historische Kennzeichnung, kein Produkt- oder Versionsname.
